# Rent Tracker - Shaik Ziya (complete project)

Includes everything: 11 houses, monthly rent tracking, yearly report,
Google Drive backup/restore, year box fix.

## How to make the APK
1. On GitHub create a NEW repository (delete the old one if you want a clean start).
2. Upload ALL files and folders from this project (including the .github folder).
3. Open the Actions tab > Build APK > wait for the green tick (about 3 minutes).
4. Open the finished run > Artifacts > download RentTracker-APK > unzip > app-debug.apk.
5. Install on your phone (allow Install unknown apps).
If you install over an older version, your data is kept.
